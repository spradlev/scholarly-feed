# Scholarly Feed

Scholarly Feed is a planned, distraction-free reader for scholarly and scientific articles, with a focus on intentional reading and offline access.

## Project status

The repository currently contains product and implementation planning documents. The Android application has not been created yet, so there are no app build or run commands at this stage.
